_Luanti_ is a game creation platform designed to generate [voxel](https://en.wikipedia.org/wiki/Voxel) worlds. While its possible to create modifications for games that already run on _Luanti_, _Digi-Terra_ is a project to script a new game from the ground up.

## The Least Amount of Content Possible

When stripped down to its minimal core, the least amount of content needed for _Luanti_ to run a game is only two nodes: "stone" and "water source". _Luanti's_ map generation automatically takes those two types of block and procedurally generates a world of ocean basins and crustal highlands from them.

### Water and Stone

Its possible to give these stone and water nodes any characteristics recognized by the engine, so the "stone" could theoretically be dirt or wood and the "water" sap to create some kind of "living planet" world.

### Biomes

Additional nodes for a _Luanti_ game are added by registering "biomes" with the core; which is where sandy beaches, grassy fields, snow-capped mountains, etc. are introduced.

## The Theme of Digi-Terra

The _Digi-Terra_ project is focused on delivering a slight twist to the standard _Minecraft_ clone. Where _Minecraft_ games are a simulation of natural worlds in a very digital, pixelated style _Digi-Terra_ is meant to be a digital world akin to the computer world of _Tron_ or _ReBoot_.
