# Digi-Terra

## Installation

If you don't already have Luanti installed, follow the instructions at the [Luanti forge](https://github.com/luanti-org/luanti) to clone and compile Luanti. If you cloned and compiled Luanti yourself, the games subfolder should be at the following location.

    cd ~/luanti/games

Next, clone the Digiterra forge.

    git clone https://github.com/ericabxy/digi-terra.git

Digiterra is now ready to go. Return to the Luanti root folder and start the game.

    cd ~/luanti
    bin/luanti

Digiterra will be selectable as a game in the "Start Game" tab. Just click New to generate a new world and Play Game to get started playing.
